# Hybrid Approaches to Collaborative Filtering

This project explores collaborative filtering techniques for building personalized movie recommendation systems. It uses movie-rating data to investigate recommender models, compare approaches, and examine how model tuning can affect recommendation performance.

## Project Contents

- `Collaborative Filtering.ipynb` – notebook for exploring collaborative filtering.
- `Recommender_Models.ipynb` – notebook containing recommender model experiments.
- `HYPER-PARAM TUNING.ipynb` – notebook for hyperparameter-tuning experiments.
- `ml-1m/` – MovieLens 1M dataset files.
- `movies.csv`, `ratings.csv`, `tags.csv` – movie, rating, and tag data files.

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Kavish718/HybridApproachesToCollaborativeFiltering.git
   cd HybridApproachesToCollaborativeFiltering
   ```

2. Set up a Python environment and install Jupyter Notebook:

   ```bash
   python -m pip install notebook
   ```

3. Install any additional Python libraries required by the notebooks. Check the import statements at the beginning of each notebook.

4. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the notebooks and run the cells in order. Make sure the dataset files are available at the paths expected by each notebook.

## Dataset

The repository includes MovieLens-related movie, rating, and tag data, including an `ml-1m` directory. The data is used to explore user preferences and movie recommendation methods.

## Project Goals

- Explore collaborative filtering for movie recommendations.
- Experiment with recommender models and compare their results.
- Investigate hyperparameter tuning and its impact on model performance.
- Understand how recommendation approaches can be used to produce personalized suggestions.

This repository contains exploratory notebooks. The exact models, evaluation metrics, and results are documented in the corresponding notebooks.
